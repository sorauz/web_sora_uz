2. GET /SORA/hs/for_msp/order (Buyurtma holatini tekshirish)
Mijoz shaxsiy kabinetida o'z buyurtmalarining joriy holatini (Status) ko'rishi uchun ishlatiladi.

So'rov parametrlari (URL Query):

?order_id=a1b2c3d4-e5f6-7a8b-9c0d-e1f2a3b4c5d6 (POST dan qaytgan order_id majburiy).

Javoblar (Responses):

200 OK:

JSON
{
  "order_id": "a1b2c3d4-e5f6-7a8b-9c0d-e1f2a3b4c5d6",
  "order_number": "000000015",
  "order_date": "2026-10-28T14:30:00",
  "status": "Tasdiqlangan", 
  "without_delivery": false,
  "total_amount": 345000
}
Izoh: status maydoni 3 xil qiymat qaytarishi mumkin:

"Jarayonda" – Buyurtma 1C ga tushgan, lekin hali menejer tomonidan tasdiqlanib ombordan hisobdan chiqarilmagan (Проведен emasm).

"Tasdiqlangan" – Hujjat tasdiqlangan (Проведен).

"Bekor qilingan" – Hujjat o'chirishga belgilangan (Пометка удаления).

400 Bad Request: ID formati xato (GUID emas) yoki umuman yuborilmagan.

404 Not Found: Yuborilgan ID bo'yicha 1C dan hujjat topilmasa.
