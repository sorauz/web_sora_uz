API Dokumentatsiyasi: Foydalanuvchini bazadan qidirish (Avtorizatsiya)

Ushbu API usuli veb-saytda ro'yxatdan o'tgan mijoz tizimga kirmoqchi bo'lganida (avtorizatsiya paytida), uning 1C bazasidagi mavjud yoki mavjud emasligini tekshirish va unga tegishli unikal ID (UUID) ni olish uchun ishlatiladi.

1. Asosiy ma'lumotlar
URL (Base): [http://1cloud.uz:777](http://1cloud.uz:777)

Endpoint: /SORA/hs/for_msp/register

Metod: GET

Content-Type: application/json; charset=utf-8

2. So'rov parametrlari (Query Parameters)
So'rov manzil qatorida URL parametrlari orqali yuboriladi. Parametrlar mijoz turiga (type) qarab farq qiladi.

Parametr nomi,Ma'lumot turi,Majburiymi?,Tavsif
type,String,Ha,Mijoz turi. Ruxsat etilgan qiymatlar: B2C (Jismoniy shaxs) yoki B2B (Yuridik shaxs).
phone,String,Shartli,Faqat type=B2C bo'lganda majburiy. Mijozning telefon raqami (bazadagi Тел1 yoki Тел2 bo'yicha qidiriladi). Format: +998... yoki 998... (bazada qanday saqlanganiga qarab).
inn,String/Number,Shartli,Faqat type=B2B bo'lganda majburiy. Yuridik shaxsning 9 xonali STIR (ИНН) raqami.

3. Javoblar (Responses)
✅ Muvaffaqiyatli javob: 200 OK
Foydalanuvchi bazadan muvaffaqiyatli topilganda, tizim uning ma'lumotlarini JSON ob'ekt ko'rinishida qaytaradi.

1-holat: B2C (Jismoniy shaxs) uchun so'rov va javob
So'rov: GET /SORA/hs/for_msp/register?type=B2C&phone=+998903265458
