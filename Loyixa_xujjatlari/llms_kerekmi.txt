Sig'dirgan taqdirda ham, kerakli ma'lumotni topishda gallyutsinatsiya kuchayadi va javob qaytarish vaqti (latency) oshib ketadi.

Axborotning tozaligi (Signal-to-Noise Ratio): Mahsulotning oddiy veb-sahifasida (HTML) juda ko'p "shovqin" bor: navigatsiya menyulari, footer, Tailwind CSS klasslari, JavaScript kodlari va tavsiya etilgan boshqa mahsulotlar karusellari. AI agentiga bular umuman kerak emas. Unga mahsulotning nomi, narxi, qoldig'i (shtrix kod, artikul) va xususiyatlari toza matn ko'rinishida kerak.

Agentlarning qidirish mantig'i: Avtonom agent (masalan, siz qurayotgan Playwright yoki multi-agent tizimidagi qidiruvchi agent) biron bir mahsulotni qidirganda, dastlab asosiy /llms.txt ga qaraydi. 📜 Standart nima deydi? Majburiyatmi yoki tavsiyami?

llmstxt.org dagi rasmiy taklifda aniq ko'rsatilgan:

"We furthermore propose that pages with information that agents might need provide a clean markdown version of those pages at the same URL as the original page, either with .md appended..."

Bu yerda "propose" (taklif qilmoq) so'zi ishlatilgan. Standartning majburiy qismi faqat llms.txt faylining o'zida (H1 sarlavha va tavsif) bo'lib, sahifalarning Markdown nusxalari ixtiyoriy ravishda tavsiya etiladi, talab qilinmaydi. Buni turli manbalar ham tasdiqlaydi: "The proposal also suggests offering clean Markdown versions of pages... Those are optional, and most sites skip them". Docusaurus plagini hujjatida ham aynan shu ta'kidlanadi: "Optionally writes individual .md files per page, which the llmstxt.org spec recommends".

🤔 Unda nima uchun page.md fayllari tavsiya etiladi?
Garchi majburiy bo'lmasa-da, har bir muhim sahifa uchun toza Markdown nusxasini yaratishning amaliy afzalliklari bor. Buni AI agentlar nuqtai nazaridan ko'rib chiqaylik:

Bu, ayniqsa, agentlar uchun samarali: ular butun "kitobni" emas, faqat kerakli "bobni" o'qiydi.

2. Toza va strukturaviy ma'lumot
HTML sahifalar navigatsiya, reklama va JavaScript bilan to'la bo'lib, ularni toza matnga aylantirish qiyin. page.md fayli esa mahsulot tavsifi, narxi, xususiyatlari kabi ma'lumotlarni allaqachon toza Markdown formatida taqdim etadi. Bu agentning ma'lumotni noto'g'ri talqin qilish xavfini kamaytiradi.

3. Standartga muvofiqlik va "kelajakka tayyorlik"

Bu amaliyot AI agentlar ekotizimida tobora standartlashib bormoqda. Uni hozirdan joriy etish saytingizni kelajakdagi agentlar uchun tayyor holatga keltiradi.

⚙️ Qanday qilib to'g'ri amalga oshiriladi?
Agar page.md fayllarini yaratishga qaror qilsangiz, standart quyidagi usullarni taklif qiladi:

Bog'lanish (link relation): HTML sahifa kodi orqali AI agentlarga Markdown versiyasi mavjudligini bildirish uchun rel="alternate" type="text/markdown" atributi qo'shiladi. Bu agentga sahifaning toza matn nusxasini avtomatik topish imkonini beradi.
